# Developer Portfolio

A responsive developer portfolio showcasing frontend web projects, technical skills, and experience.

Live Site: https://obehi-dev.vercel.app

## Tech Stack

* React
* Tailwind CSS
* Vite
* Lucide React
* Vercel

## Features

* Responsive layout across mobile, tablet, and desktop views
* Custom mobile navigation menu
* Projects showcase and about section
* Direct contact link and social profiles

## Local Setup

1. Clone the repository:
   git clone https://github.com/Obehi123-beep/portfolio.git

2. Navigate into the directory:
   cd portfolio

3. Install dependencies:
   npm install

4. Run the development server:
   npm run dev
